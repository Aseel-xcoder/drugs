# الدليل اليمني الشامل للأدوية — نسخة الويب

نسخة ويب ثابتة (Static) من تطبيق الأدوية — تعمل في أي متصفح بدون تثبيت
وبدون تسجيل دخول. لا خادم، لا قاعدة بيانات خارجية، لا تتبّع.

## التشغيل محلياً

ملفات JSON تُحمَّل عبر `fetch`، لذلك لا تعمل بفتح الملف مباشرة
(`file://`) — شغّل أي خادم ثابت من داخل هذا المجلد:

```bash
cd ~/workspace/aseel-drugs-web
python3 -m http.server 8000
# ثم افتح: http://localhost:8000/
```

## النشر (Deploy) — لم يتم بعد

التطبيق ملفات ثابتة 100%، فيحتاج فقط:

1. **دومين أو نطاق فرعي نظيف** — مثل `app.example.com` — لكي يكون الرابط
   احترافياً مثل `https://app.mediscoreplatform.com/home`.
   المستخدم لا يملك دوميناً بعد؛ القرار بيده (شراء دومين ~10–15 دولار/سنة).
2. **استضافة ثابتة (Static hosting)** تشير إليها سجلات DNS — أي خدمة
   استضافة ثابتة مجانية أو مدفوعة (مثال: Cloudflare Pages، Netlify،
   GitHub Pages، أو أي خادم ويب). ارفع محتويات هذا المجلد كما هي،
   ووجّه الدومين/النطاق الفرعي إلى الاستضافة.
3. لا حاجة لأي خادم تطبيقات أو قاعدة بيانات أو شهادات خاصة —
   الاستضافة توفّر HTTPS تلقائياً.

لم يُنشر على أي رابط — لا يوجد رابط عام بعد. لا تستخدم روابط مؤقتة
أو غريبة الشكل لإرساله للناس.
